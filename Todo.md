# 30. Important Team Rule

**Do not build everything simultaneously without integration.**

Use this sequence:

```text
Requirements
     ↓
Architecture
     ↓
API + Database Contract
     ↓
Frontend + Backend + AI Development
     ↓
Weekly Integration
     ↓
MVP
     ↓
AI Integration
     ↓
Testing
     ↓
Evaluation
     ↓
Deployment
     ↓
University Demo
```

Every week, the four developers must integrate their work into `develop`.

A feature is not considered complete merely because it works on one developer's computer.

It is complete when:

```text
Code
 ↓
Tests
 ↓
Pull Request
 ↓
Review
 ↓
CI
 ↓
Merge
 ↓
Integrated System
```
